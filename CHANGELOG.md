# Changelog

## 0.1.0

- First release of ArgoCD & Flux GitOps Viewer for VS Code.
- Offline parser and visual inspector for ArgoCD (`Application`, `ApplicationSet`, `AppProject`) and Flux v2 (`GitRepository`, `HelmRepository`, `OCIRepository`, `Kustomization`, `HelmRelease`) YAML manifests.
- Dedicated tabs for Apps & Resources, Sources & Repos, Sync & Reconcile, Destinations & Scope, and Static Findings.
- Pro tools (1 free try each): Markdown GitOps sync and security audit, side-by-side manifest diff, and local Markdown/CSV inventory export.
